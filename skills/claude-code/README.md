# Claude Code

Claude Code 자산(skill·slash command·sub-agent·hook)을 만들고 사용 이력을 분석하는 도구. 플러그인에 포함된다.

- **[skill-creator](./skill-creator/SKILL.md)**: 새 skill 을 설계·생성·패키징한다.
- **[slash-command-creator](./slash-command-creator/SKILL.md)**: slash command 를 만든다.
- **[subagent-creator](./subagent-creator/SKILL.md)**: 전용 sub-agent 를 만든다.
- **[hook-creator](./hook-creator/SKILL.md)**: Claude Code hook 을 만들고 설정한다.
- **[cc-usage-audit](./cc-usage-audit/SKILL.md)**: 한 프로젝트의 Claude Code 프롬프트 이력을 분석해 사용 패턴·개발 철학·개선점을 뽑는다.
