# Engineering

코드 작업에 매일 쓰는 skill. 플러그인에 포함된다.

- **[commit](./commit/SKILL.md)**: 대화 맥락을 근거로 변경을 의미 단위로 나눠 커밋하고 push 한다. `HARNESS_HEADLESS=1` 무인 모드를 지원한다.
- **[ship](./ship/SKILL.md)**: 커밋 → push → PR 생성 → squash merge 를 한 번에 한다. 워크트리에서도 안전하다.
- **[domain-storytelling](./domain-storytelling/SKILL.md)**: 기획 전에 AI가 나를 인터뷰해 업무 흐름·문제·해결 범위를 `docs/DOMAIN.md`로 남기는 도메인 스토리텔링 워크숍.
- **[infra-map](./infra-map/SKILL.md)**: 클라이언트·서버·외부 제공자 칸의 인프라 지도를 `docs/infra-map.json`으로 관리하고, 기능 하나의 요청이 지나가는 길(리퀘스트 맵)을 손그림 지도로 그린다(의존성 없음).
