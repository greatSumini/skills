# Productivity

코드 밖 업무 도구. 플러그인에 포함된다.

- **[gmail](./gmail/SKILL.md)**: gogcli 로 Gmail 을 검색·조회·발송한다.
- **[google-calendar](./google-calendar/SKILL.md)**: gogcli 로 Google Calendar 일정을 조회·생성·수정·삭제한다.
- **[email-draft](./email-draft/SKILL.md)**: 비즈니스 메일·답장 초안을 쓸 때의 글쓰기 매너.
- **[transcribe](./transcribe/SKILL.md)**: 로컬 오디오 파일(m4a 등)을 한국어로 전사한다.
- **[youtube-collector](./youtube-collector/SKILL.md)**: 유튜브 채널을 등록하고 새 영상을 모아 자막 기반 요약을 만든다.
- **[discord-message](./discord-message/SKILL.md)**: Discord 봇으로 나에게 DM 을 보낸다. 설정은 `~/.config/discord-message/config.json`.
